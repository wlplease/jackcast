# Source provenance

Jackcaster began as a copy of the open-source Selfcaster project by
[GenuineJack](https://github.com/GenuineJack/selfcaster). The first Jackcaster
commit is `b33b2f0b2b9ff3496feda21b46e8d86571ba56c1` (2026-10-18). Its Git tree
hash is `36b875cf85cf4104c35a61d36866859980dead2a`.

On 2026-10-21, the Selfcaster upstream `main` HEAD was
`e1735dcfe836d30bd3166626cb7b929be911940d`, with the same exact tree hash:
`36b875cf85cf4104c35a61d36866859980dead2a`. This proves the initial Jackcaster
snapshot matches that Selfcaster source snapshot byte-for-byte. The repositories
were copied with separate Git histories, so they have no shared Git ancestor;
the matching tree hash is the provenance link.

The local `upstream` remote points to
`https://github.com/GenuineJack/selfcaster.git`. Future upstream changes should
be fetched and reviewed before merging. Jackcaster-specific changes start after
the initial copied snapshot and remain in this repository.

This records source provenance, not the state of any hosted deployment. To
inspect the fork's changes from the copied snapshot, compare the current tree
with commit `b33b2f0b2b9ff3496feda21b46e8d86571ba56c1`. Historical commit
messages before this documentation were not rewritten; rewriting them would
change existing commit identities.
